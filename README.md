# TD7_PhotoBox

    TD7 fait jusqu'à l'exercice 4 (navigation des photos à l'aide de la gallerie)

    se mettre à la racine du porjet et faire :
    
        - npm install

        - npm run build

    Fonctionnalité :
        - chargement d'une photo
        - chargement de la categorie de la photo
        - chargement de la gallerie
        - navigation dans la gallerie
        - chargement de photo en cliquant dans la gallerie
